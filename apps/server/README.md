# my-app

ASP.NET Core project generated by Better Fullstack.

## Commands

```bash
dotnet restore
dotnet test my_app.Tests
dotnet run
```

## Stack

- Framework: aspnet-mvc
- Data access: dapper
- Auth: aspnet-identity
- API style: minimal-api
- Realtime: signalr
- Observability: serilog
- Libraries: automapper
- Deploy: docker

The selected application libraries are restored as pinned NuGet references. They are intentionally
left unregistered until you supply the app-specific transports, credentials, endpoints, and domain
types their production configuration requires.
